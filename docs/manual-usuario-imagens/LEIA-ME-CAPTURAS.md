# Capturas para o Manual do Utilizador (secção 6)

Os ficheiros abaixo são **referenciados** no documento `docs/manual-do-usuario-6.md`.  
Deve **adicionar as suas próprias imagens** (prints de ecrã) com estes nomes, ou renomear os seus prints para coincidir.

## Padronização (obrigatório para o relatório)

1. **Proporção:** use sempre a mesma, por exemplo **16:9** (ex.: 1280×720 ou 1600×900).
2. **Largura no Word/PDF:** redimensione todas para a **mesma largura** (ex.: 14 cm ou 900 px).
3. **Moldura:** no Word, selecione a imagem → **Formatar imagem** → **Contorno** → linha fina cinzenta (para separar do fundo branco).
4. **Anotações:** use o Editor de Fotos do Windows, PowerPoint ou ferramenta à escolha para desenhar **setas**, **círculos** ou **números (1, 2, 3)** sobre o print, alinhados ao texto do manual.
